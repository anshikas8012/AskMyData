# AskMyData 📊

### Ask Questions. Get SQL. Discover Insights.

AskMyData is an AI-powered Text-to-SQL project that aims to convert natural language questions into SQL queries and help users explore data without writing SQL manually.

## 🎯 Project Objective

The goal of this project is to make data analysis easier by allowing users to ask questions in simple English and get meaningful results from a database.

## ✨ Planned Features

* Convert natural language questions into SQL queries.
* Execute SQL queries on a database.
* Display query results in an easy-to-understand table.
* Visualize data using charts and graphs.
* Provide useful insights from data.

## 🛠️ Tech Stack

* Python
* SQL
* SQLite
* Streamlit
* Pandas
* AI/LLM integration (planned)

## ⚙️ How It Will Work

1. The user enters a question in simple English.
2. The application generates an SQL query.
3. The query runs against the database.
4. Results appear in a table with visualizations where appropriate.

## 🚧 Project Status

Currently in development. Features will be implemented step by step.
